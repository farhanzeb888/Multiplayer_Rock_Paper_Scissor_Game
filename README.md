🎮 Multiplayer Rock Paper Scissor Game

A simple real-time multiplayer Rock-Paper-Scissors game built with HTML, CSS, and JavaScript.

# Features
Two players can play Rock-Paper-Scissors simultaneously
Clean, minimalist UI (HTML + CSS)
Responsive design for different devices
Simple, intuitive gameplay
Instant feedback on winner / tie

# Getting Started
# Prerequisites
A modern web browser (Chrome, Firefox, Edge, Safari)

---
# Installation
Clone this repo:
git clone https://github.com/farhanzeb888/Multiplayer_Rock_Paper_Scissor_Game.git

# Navigate into project folder:

cd Multiplayer_Rock_Paper_Scissor_Game
Running the Game
Simply open index.html in your browser to play locally.
For a true multiplayer version over the network or internet, you would need to integrate a backend / WebSocket server.

---
# How It Works
index.html — Main UI and game layout
styles.css — Handles all styling, layout, responsive design
script.js — Main game logic:
Handling user input (choosing rock / paper / scissors)
Determining outcome between players (win / lose / tie)
